Descripción del modelo

Arquitectura

CharRNN autorregresivo: Embedding(29, 32) → celda recurrente (RNN / LSTM / GRU, hidden=128, 1 capa) → Linear(128, 29). Vocabulario fijo: a–z + tokens especiales <PAD>, <SOS>, <EOS>.

Datos

1 536 nombres reales de dinosaurios (dinos.csv). Se filtran a minúsculas y solo letras a–z. T = max(len) + 2 para incluir SOS/EOS.

Entrenamiento

CrossEntropyLoss(ignore_index=PAD) sobre X = [x₀..x_{T-1}], Y = [x₁..x_T]. Adam lr=1e-3, batch 64, hasta 50 épocas con early stopping (patience=5).

Curvas de aprendizaje

Muestreo

Generación autorregresiva desde <SOS> con tres palancas: temperature (escala los logits), top-k (mantiene los k más probables), top-p / nucleus (mantiene la masa acumulada hasta p). Recomendación final: T=1.0, top_p=0.9 — balance entre originalidad y plausibilidad.

Ejemplos generados

10 nombres seleccionados del barrido completo, descritos por un LLM local (gemma2:2b vía Ollama) e ilustrados con difusión (amused-512).
